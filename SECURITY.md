# Security policy

## Supported versions

This project is under active development.  Reports concerning the current maintained code will be assessed case by case.

## Reporting a vulnerability

Please report suspected vulnerabilities privately.  Use GitHub's [private vulnerability reporting](https://github.com/RamrattanN/Ramrattan-AI-Editorial-Studio/security/advisories/new) when available.  If it is unavailable, email **info@ramrattan.com** with the subject **Ramrattan-AI-Editorial-Studio security report**.

Include the affected version or commit, clear steps to reproduce, a proof of concept if available, the possible impact, and a way to contact you.  Please do not publish exploit details in an issue or pull request while a report is being investigated.  Do not include an Author's unpublished work, private source material, credentials, or other people's personal information in a report.

The maintainer will acknowledge and review the report, coordinate a fix and disclosure where appropriate, and publish a GitHub security advisory when warranted.  Reasonable credit will be given upon request after a fix is released.  No fixed response or resolution time is promised.
