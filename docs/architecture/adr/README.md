# Architecture Decision Records

Architecture Decision Records - ADRs - capture significant product,
architecture, engineering, and governance decisions.

Each ADR explains:

- Context
- Decision
- Alternatives considered
- Consequences
- Status

## Status Values

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected
