# Capability 011 Demo - Portable Editorial Project

## Outcome

Capability 011 provides offline, Author-owned project continuity without
inventing context the current runtime does not possess.

## Demonstration

1. Build the existing Publication Package and optionally attach its validated
   Hero Visual.
2. Create a schema-version-1 Portable Editorial Project using a daily
   `YYYY.MM.DDvNN` filename.
3. Serialize it to deterministic, human-readable Markdown.
4. Deserialize the Markdown and reject malformed, unsupported, invalid, or
   blocked state.
5. Resume a paused Editorial Session and surface the mandatory Temporal
   Integrity review; an older saved date is explicitly stale.
6. Download the article, validated Hero Visual, project Markdown, or a
   deterministic optional ZIP.

The approved article bytes and Hero Visual bytes remain unchanged. No legacy
Author profile, Adaptive Editorial Context, rich source archive, publication
history, workspace, collaboration, orchestration, UI, or Version 2 state is
fabricated.
