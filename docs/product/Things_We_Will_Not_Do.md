# Things We Will Not Do

- We will not force a fixed creative sequence.
- We will not require premature categorization.
- We will not overwrite the Author's perspective.
- We will not discard context silently.
- We will not confuse approval with permanence.
- We will not treat every source as correct.
- We will not present inference as fact.
- We will not imitate reference posts.
- We will not optimize for maximum output.
- We will not build around one AI provider.
- We will not make the interface the product.
